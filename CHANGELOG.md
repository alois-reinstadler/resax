[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## Versioning policy

- Breaking consumer source or public API changes increment the major version; before `1.0.0`, they increment the minor version.
- Additive components and backwards-compatible features increment the minor version.
- Backwards-compatible fixes increment the patch version.
- Each released registry snapshot receives a changelog entry. Registry source and generated JSON are versioned together; Resax is not published as an npm package.
