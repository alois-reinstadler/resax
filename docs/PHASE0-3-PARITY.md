## Behavior checklist

- State uses Svelte 5 bindables and callback props.
- Interactive elements use native controls, Bits UI, or official shadcn-svelte primitives.
- Runtime colors use Resax tokens and animation has reduced-motion handling.
- SSR-sensitive families avoid browser globals during server render.

## Material fixes

Spinner accepts all canonical source names. Card adds spotlight and tilt-3d; Indicator adds odometer; ContextMenu adds radial; Input, Textarea, and Select expose source-specific treatments. Popup and Drawer use official shadcn-svelte Dialog and Sheet bases.

## Remaining fidelity notes

Some visually named demos are intentionally orthogonal compositions (for example Drawer blur/glass use surface tokens and Card asset/slider use media snippets). No material Phase 0–3 family is absent.
